# 个人素材库（模板）

> 真实的"人味"不能靠 AI 编造，必须来自真实素材。
> 把你的真实经历、观点、口头禅沉淀在这里，生成文章时优先调用。

## 真实经历

> 记录你的真实小故事、场景、细节。生成文章时，AI 会从这里选取合适的素材插入。

```yaml
stories:
  # 格式：场景 + 细节 + 感受
  # - scene: "上周三在星巴克改稿"
  #   detail: "旁边坐了个大哥在用ChatGPT写周报，写了删删了写"
  #   feeling: "突然觉得AI时代每个人都在摸索"
  #   tags: ["AI", "日常", "观察"]
  
  # - scene: "第一次用AI写公众号"
  #   detail: "生成了5个标题，每个都像营销号"
  #   feeling: "工具是好工具，但得调教"
  #   tags: ["AI写作", "踩坑"]
```

## 真实观点

> 你对各种话题的真实看法。不需要政治正确，只需要真实。

```yaml
viewpoints:
  # 格式：话题 + 你的观点 + 一句话总结
  # - topic: "AI会取代程序员吗"
  #   view: "不会取代，但会淘汰不会用AI的程序员"
  #   one_liner: "AI是放大器，不是替代品"
  
  # - topic: "公众号还值得做吗"
  #   view: "值得，但不是靠日更，而是靠深度"
  #   one_liner: "一篇好文章顶一百篇水文"
```

## 口头禅和语言习惯

> 你说话的方式，让 AI 学会用你的语气。

```yaml
phrases:
  favorites:
    # - "说人话"
    # - "别整虚的"
    # - "这事儿吧..."
  
  avoid:
    # - "赋能"
    # - "生态闭环"
    # - "降维打击"
    # - "颗粒度"
  
  tone_notes:
    # - "喜欢用反问"
    # - "经常自嘲"
    # - "不喜欢感叹号"
```

---

**使用说明：**
- 取消注释并填入你的真实内容
- 不需要一次填完，随时补充
- AI 生成文章时会优先从这里选取素材
- 这个文件是私有的（.gitignore 已配置），不会被提交到公共仓库
