# 文章结构原型

> 不要每篇都用"开头钩子 → 3-5小节 → 结尾CTA"。根据主题类型选择合适的结构。

## 1. 标准分节（standard）

适用：干货分享、技术解析、产品评测

```
开头钩子（1-3句，制造好奇）
↓
小节1：问题/背景
↓
小节2：核心观点/方法
↓
小节3：案例/证据
↓
小节4（可选）：延伸思考
↓
结尾：行动号召或金句
```

特点：结构清晰，信息密度高，适合"有用"类内容。

---

## 2. 时间线叙事（timeline）

适用：个人经历、项目复盘、行业变迁

```
时间锚点1："三个月前..."
↓
转折/冲突："但是..."
↓
时间锚点2："上周..."
↓
高潮/发现
↓
现在的状态 + 感悟
```

特点：有画面感，读者跟着时间线走，不容易跳出。注意每个时间锚点要有具体细节（地点、天气、对话）。

---

## 3. 问答对话体（dialogue）

适用：观点输出、争议话题、科普解释

```
抛出一个常见问题/误解
↓
"很多人会说..."（呈现主流观点）
↓
"但真相是..."（反转）
↓
再抛一个问题
↓
再反转
↓
最终结论（不一定要给确定答案）
```

特点：节奏快，有对抗感，适合观点类。注意不要变成自问自答的说教。

---

## 4. 清单体（listicle）

适用：工具推荐、方法论、经验总结

```
开头：为什么写这个清单（1-2句）
↓
第1条：标题 + 一句话解释 + 一个具体例子
↓
第2条：...
↓
...（5-10条）
↓
结尾：最重要的一条是哪个 + 行动建议
```

特点：扫读友好，适合手机阅读。注意每条之间要有递进或分类逻辑，不要纯罗列。

---

## 选择规则

| 主题类型 | 推荐结构 | 备选结构 |
|---------|---------|---------|
| 赚钱/变现 | 时间线叙事 | 标准分节 |
| 技术/工具 | 标准分节 | 清单体 |
| 观点/洞察 | 问答对话体 | 标准分节 |
| 经验/复盘 | 时间线叙事 | 清单体 |
| 推荐/盘点 | 清单体 | 标准分节 |
| 故事/案例 | 时间线叙事 | 问答对话体 |

## 反重复规则

- 连续2篇不能用同一种结构
- 如果 DNA 的 `recent_articles` 中最近2篇都是同一结构，强制切换
