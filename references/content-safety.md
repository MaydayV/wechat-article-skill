# 内容安全与合规指南

> 公众号文章涉及的合规风险分级和应对策略。

## 风险分级

### 🔴 高风险话题（必须人工确认后才能发布）

| 话题类型 | 风险点 | 应对策略 |
|---------|--------|---------|
| 政治/时政 | 立场敏感、政策解读偏差 | 只引用官方原文，不做主观解读 |
| 金融/投资 | 构成投资建议、承诺收益 | 必须加"不构成投资建议"声明 |
| 医疗/健康 | 构成诊疗建议、虚假疗效 | 必须加"请咨询专业医生"声明 |
| 法律 | 构成法律意见 | 必须加"请咨询专业律师"声明 |
| 军事/国防 | 涉密、不实信息 | 避免涉及，只引用公开报道 |

### 🟡 中风险话题（需要软化表达）

| 话题类型 | 风险点 | 应对策略 |
|---------|--------|---------|
| 行业分析 | 数据不实、误导判断 | 标注数据来源，用"据公开信息"限定 |
| 人物评价 | 名誉侵权 | 只评价公开行为，不评价人品 |
| 产品对比 | 不正当竞争 | 客观陈述，不贬低竞品 |
| 教育/考试 | 误导决策 | 标注"个人经验，仅供参考" |

### 🟢 低风险话题

技术分享、个人感悟、工具推荐、生活随笔等。正常写作即可。

## 禁止声明

以下表达绝对不能出现在文章中：

- "保证收益" / "稳赚不赔" / "零风险"
- "100%有效" / "包治百病" / "立竿见影"
- "国家机密" / "内部消息" / "独家爆料"
- "不转不是中国人" / 任何形式的道德绑架转发
- 未经授权的他人隐私信息

## 安全写法模板

### 涉及数据时
```
❌ "据统计，80%的创业者会在第一年失败"
✅ "根据公开数据，创业早期的失败率相当高"
✅ "据《XX报告》（2025年）显示，约80%的创业者..."（附来源）
```

### 涉及建议时
```
❌ "你应该立刻去买XX"
✅ "以我个人经验来看，XX值得关注，但请根据自身情况判断"
```

### 涉及他人时
```
❌ "XX公司就是骗子"
✅ "从公开信息来看，XX公司的做法存在争议"
```

## 发布前检查清单

生成文章后，`validate_article.py` 会自动检查：

1. **禁止声明扫描** — 是否包含上述禁止表达
2. **风险话题识别** — 是否涉及高/中风险话题
3. **硬事实标记** — 包含具体数字/数据的句子是否有来源
4. **免责声明检查** — 高风险话题是否附带了对应的免责声明
